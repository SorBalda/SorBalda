# Andrea Baldanza

Ph.D. student at Sapienza University of Rome. I build experimental systems,
terminal interfaces, and strange little worlds where software feels like a
place.

## VibeWorld

[VibeWorld](https://github.com/SorBalda/vibeworld) is a persistent cyberpunk
multiplayer world that runs entirely in your terminal: shared neon cities,
pixel avatars, voice chat, arcade games, and a rocket to the moon when your AI
agent deletes the failing test.

[![VibeWorld: from space to a shared terminal city](https://raw.githubusercontent.com/SorBalda/vibeworld/main/docs/screenshots/journey.gif)](https://github.com/SorBalda/vibeworld)

```sh
curl -fsSL https://raw.githubusercontent.com/SorBalda/vibeworld/main/install.sh | sh
vibeworld
```
